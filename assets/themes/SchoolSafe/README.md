# SchoolSafe theme

LOT-01 shell. This theme loads FlatSIS, then replaces the sidebar, top bar, type and tokens.

Rosario still builds the menu, checks permissions and writes PostgreSQL. No program is removed.

`logo.png` is the SchoolSafe mark with the black background removed. Token values in `stylesheet.css` were measured from that logo.

Rollback: set the school theme back to `FlatSIS` in School > Configuration.
