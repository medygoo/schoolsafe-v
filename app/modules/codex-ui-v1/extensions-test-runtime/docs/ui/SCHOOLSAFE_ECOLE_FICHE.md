# Fiche de l’école

**Nom SchoolSafe.** Fiche de l’école.

**Grande branche.** École.

**Sous-branche.** Établissement. Ce n’est ni un niveau, ni un créneau, ni le calendrier.

**Où la trouver.** École, lien School Information, juste après Grade Levels.

**À quoi elle sert.** Cette page présente l’école : son nom, son adresse, son téléphone, son directeur et son site. Si vous pouvez modifier, corrigez ces informations, puis enregistrez.

**Qui peut l’utiliser.** L’administrateur peut modifier la fiche et l’enregistrer. L’enseignant, le parent et l’élève peuvent l’ouvrir. Ils ne voient le bouton Enregistrer que si Rosario les y autorise.

**Ce qu’on peut faire.** Lire le nom, l’adresse, la ville, le téléphone, le nom du directeur, le site, le nom court, le numéro d’école et l’échelle de notes. Modifier ces informations, puis enregistrer. Supprimer l’école n’est proposé que s’il en existe une autre et qu’aucun élève n’y est inscrit. Cette page ne crée pas une nouvelle école.

**Dépendances.** Le nom affiché dans l’application vient de cette fiche. Les élèves, les cours et le calendrier restent rattachés à cette école. Les champs supplémentaires, s’il en existe, viennent de la page School Fields.

**Fonction Rosario correspondante.** `School_Setup/Schools.php` (School Information). Les informations sont dans `schools`, pour l’école et l’année en cours.
