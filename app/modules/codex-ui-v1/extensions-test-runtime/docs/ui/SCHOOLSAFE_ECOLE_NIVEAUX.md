# Niveaux de l’école

**Nom SchoolSafe.** Niveaux de l’école.

**Grande branche.** École.

**Sous-branche.** Niveaux. Ce ne sont ni les périodes de l’année, ni les créneaux de la journée.

**Où la trouver.** École, lien Grade Levels, juste après Periods.

**À quoi elle sert.** Cette page liste les niveaux de l’école, par exemple la maternelle ou la 6e. Pour chacun, on indique le nom, l’ordre, et le niveau qui vient après.

**Qui peut l’utiliser.** L’administrateur peut ajouter, modifier et supprimer un niveau auquel aucun élève n’est inscrit. Sur cette école, l’enseignant, le parent et l’élève ne voient pas ce lien, et une adresse directe ne les laisse pas sur la page.

**Ce qu’on peut faire.** Ajouter un niveau, changer son nom, son nom court, son ordre ou le niveau suivant, puis enregistrer. Supprimer un niveau seulement si aucun élève n’y est inscrit.

**Dépendances.** L’inscription d’un élève peut être rattachée à un niveau. Tant qu’un élève y est inscrit, le niveau ne se supprime pas.

**Fonction Rosario correspondante.** `School_Setup/GradeLevels.php` (Grade Levels). Les niveaux sont dans `school_gradelevels`.
