# Nouvelle école

**Nom SchoolSafe.** Nouvelle école.

**Grande branche.** École.

**Sous-branche.** Établissement. La page crée une autre école en recopiant la structure de celle que vous consultez. Ce n’est pas une fiche à corriger, ni un niveau, ni un créneau.

**Où la trouver.** École, groupe Setup, lien Copy School, juste après School Information.

**À quoi elle sert.** Cette page crée une nouvelle école à partir de celle que vous consultez. Cochez ce qu’il faut recopier, indiquez son nom, puis confirmez. La configuration est toujours recopiée. La nouvelle école apparaît ensuite dans la liste des écoles, en haut de l’écran.

**Qui peut l’utiliser.** L’administrateur peut ouvrir la page et confirmer la copie. L’enseignant, le parent et l’élève ne voient pas ce lien. Rosario reste l’autorité.

**Ce qu’on peut faire.** Choisir ce qui est recopié : périodes de l’année, créneaux, niveaux, barèmes, codes de commentaires, activités et codes de présence. Donner un nom. Confirmer ou annuler. On ne peut pas modifier l’école actuelle depuis cette page, ni en supprimer une.

**Où ses données sont réutilisées.** La nouvelle école apparaît dans la liste des écoles. Si la case correspondante est cochée, les périodes, les créneaux, les niveaux, les barèmes, les commentaires, les activités et les codes de présence de la nouvelle école reprennent ceux de l’école d’origine. L’école d’origine n’est pas modifiée.

**Fonction Rosario correspondante.** `School_Setup/CopySchool.php` (Copy School), première page du groupe Setup. La nouvelle école est enregistrée dans `schools`.
