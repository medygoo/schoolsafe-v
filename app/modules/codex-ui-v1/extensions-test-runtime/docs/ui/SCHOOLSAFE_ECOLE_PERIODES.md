# Périodes de l’année

**Nom SchoolSafe.** Périodes de l’année.

**Grande branche.** École.

**Sous-branche.** Périodes. Ce n’est pas le calendrier des jours de classe. Ici, on découpe l’année.

**Où la trouver.** École, lien Marking Periods, juste après Calendars.

**À quoi elle sert.** Cette page sert à découper l’année : l’année entière, les semestres, les trimestres et les périodes plus courtes. Pour chacune, on fixe les dates, et si les notes peuvent y être saisies.

**Qui peut l’utiliser.** L’administrateur peut modifier, ajouter et supprimer une période lorsque Rosario l’autorise. L’enseignant, le parent et l’élève peuvent ouvrir la page. Ils ne voient les actions de modification que si Rosario les y autorise.

**Ce qu’on peut faire.** Choisir une période dans les listes. Vérifier son nom, son nom court, son ordre et ses dates. Indiquer si elle reçoit des notes et des commentaires, et les dates de saisie des notes. Enregistrer. Ajouter un semestre, un trimestre ou une période plus courte. Supprimer une période seulement si elle n’est pas la seule de son niveau et si rien d’important n’y est encore attaché. L’année entière affichée au départ ne se supprime pas depuis cette page.

**Dépendances.** Les cours, la présence, les devoirs, les notes et les commentaires peuvent être rattachés à une période. Le calendrier scolaire propose les dates de l’année à la création d’un calendrier, mais il ne découpe pas l’année.

**Fonction Rosario correspondante.** `School_Setup/MarkingPeriods.php` (Marking Periods). Les périodes sont dans `school_marking_periods`.
