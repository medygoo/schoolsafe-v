# Calendrier scolaire

**Nom SchoolSafe.** Calendrier scolaire.

**Sous-branche.** Calendrier. Ce n’est pas une annonce, ni un sondage, ni les périodes de l’année, ni l’emploi du temps.

**Où la trouver.** École, lien Calendars.

**À quoi elle sert.** Cette page montre les jours où l’école est ouverte, pour le calendrier de l’année. Choisissez le mois et le calendrier. Si vous pouvez modifier, indiquez les jours de classe, puis enregistrez.

**Qui peut l’utiliser.** L’administrateur peut créer, modifier et supprimer un calendrier, et régler les jours. L’enseignant voit le calendrier de son cours. Le parent et l’élève voient le calendrier de l’inscription. Eux ne voient les boutons de modification que si Rosario les y autorise.

**Ce qu’on peut faire.** Choisir le mois et le calendrier. Voir les jours complets, les jours en minutes, et les jours sans école. Créer un calendrier, le modifier, le supprimer, et enregistrer les jours. Consulter les événements du mois, ou ouvrir leur liste. L’enseignant, le parent et l’élève y voient aussi les devoirs à rendre, sans les modifier ici.

**Dépendances importantes.** Les jours enregistrés servent à la présence. Un cours et une inscription peuvent être liés à un calendrier. Les événements de cette page peuvent apparaître sur le portail. Les dates de l’année proposées à la création viennent de l’année scolaire, mais cette page ne modifie pas les périodes. L’emploi du temps reste une autre fonction.

**Fonction Rosario correspondante.** `School_Setup/Calendar.php` (Calendars). Les calendriers sont dans `attendance_calendars`. Les jours sont dans `attendance_calendar`. Les événements sont dans `calendar_events`.
