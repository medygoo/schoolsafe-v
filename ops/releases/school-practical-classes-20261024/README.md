# Top 5 des classes — vrais travaux pratiques

**Règle validée par le propriétaire :** seuls les types natifs exactement `TP` ou `Travaux pratiques` sont pris en compte, sur la période de notation sélectionnée. Une affectation de cours commun est comptée **une fois par classe/section réellement concernée**, sans multiplier par les élèves ni les notes. Le personnel affiché est celui qui a créé les affectations natives ; les devoirs futurs, autres types, autre école/année et les classes sans inscription active sont exclus. Les dates d'attribution manquantes sont acceptées seulement si la création est passée. Ex aequo au cinquième rang inclus. État vide explicite si type non configuré ou aucun TP donné. Pas de création de type, note, classe ou compte réel.

Livraison additive séparée : un nouveau lecteur natif et deux fichiers de présentation, aucun schéma/droit/session/média modifié. Image exacte qualifiée sur isolat PostgreSQL17 avec catégories, classes, enseignants et deux écoles synthétiques, HTTP authentifié, navigateur mobile/bureau et protections antérieures. Trois montages, médias, configuration, sessions et services conservés ; dump privé non restauré et prédécesseur arrêté conservé. L'école réelle auditée en lecture seule n'a actuellement aucun type TP natif, donc aucune classe réelle n'est annoncée dans la production.
