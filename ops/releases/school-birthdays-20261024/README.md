# Anniversaires scolaires — livraison séparée

Le lecteur natif déjà présent fournit les dix prochaines dates élèves/personnel de l'école et de l'année. Ce lot refuse les dates invalides ou futures et affiche le personnel au seul administrateur autorisé à lire le personnel, même si l'accès élèves lui manque. La liste ne divulgue aucun élève sans droit natif. Aucun résultat fictif ni création d'une date/personne.

Une seule source applicative est changée ; image exacte sur la précédente livraison du logo. La recette conserve les trois montages, le logo et le portrait réels, sessions/configuration/services, prend un dump privé sans le restaurer automatiquement ; sauvegardes médias locales existantes revérifiées. Qualification HTTP authentifiée seulement sur données synthétiques. L'acceptation dans la vraie session du titulaire et la copie média hors site demeurent distinctes.
