# Adaptateur JASP pour Rosario

Preparation locale : module non active automatiquement, aucun droit attribue.
Le menu declare Assistant.php pour les listes natives de programmes et droits.
La page propose une interface locale d'orientation et un brouillon de devoir avec illustration locale. Le bloc devoir exige AllowUse et AllowEdit sur Grades/Assignments.php. Aucun texte ou fichier n'est envoye a un fournisseur IA et aucun devoir n'est enregistre ou publie.

Le personnage presenter.png provient du pack v12 recupere dans schoolsafe-stable. Il s'agit d'une image fixe : les mouvements et la conversation IA restent a raccorder.

Le module n'est pas active et les essais PHP/navigateur restent a effectuer avant activation. Setup_Assistant n'est pas remplace a ce stade.

Le catalogue jaspe-actions.php exige une session, le module actif et AllowUse.
Les destinations restent filtrees par les droits metier de l'utilisateur.
Le moteur orientation.js ne cree jamais une URL depuis une reponse IA.
