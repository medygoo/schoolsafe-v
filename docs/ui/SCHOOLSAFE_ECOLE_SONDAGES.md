# Sondages du portail

**Nom SchoolSafe.** Sondages du portail.

**Sous-branche.** Sondages. Ce n’est pas une annonce : ici on pose une question et on propose des choix.

**Où la trouver.** École, lien Portal Polls.

**À quoi elle sert.** Cette page permet de préparer les sondages du portail : le titre, les questions, les choix, l’ordre, les dates, et les personnes qui peuvent les voir. Chacun répond une seule fois, sur le portail. Le décompte peut être affiché.

**Qui peut l’utiliser.** Un administrateur. Les enseignants, les parents et les élèves ne voient pas ce lien. Ils peuvent répondre seulement si le sondage est publié pour leur profil, et ils le font sur le portail.

**Ce qu’on peut faire.** Créer un sondage, écrire chaque question, mettre un choix par ligne, choisir une seule réponse ou plusieurs, ajouter une autre question, régler l’ordre, les dates et les profils, afficher ou non le décompte, enregistrer, modifier, supprimer. Un sondage dont la date de fin est passée reste dans la liste, avec son titre en rouge. Si le public enregistré comprend les élèves, on peut limiter le sondage aux élèves d’un enseignant.

**Fonction Rosario correspondante.** `School_Setup/PortalPolls.php` (Portal Polls). Les sondages sont dans `portal_polls`. Les questions, les choix et les décomptes sont dans `portal_poll_questions`.
