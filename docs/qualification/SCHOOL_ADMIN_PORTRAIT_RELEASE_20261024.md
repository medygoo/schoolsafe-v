La source JSON authentifiée `central-navigation.php` retrouve uniquement `User('STAFF_ID')` courant et sa photo `staff_id.*jpg`. Le correctif PHP de cette livraison empêche l'assistant de présenter un dépôt comme réussi si `ImageUpload()` renvoie simplement la chaîne base64 après échec de création du dossier. Le montage dédié rend cette écriture persistante. Aucun identifiant, école ou image n'est codé en dur dans le produit.
